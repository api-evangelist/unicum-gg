# unicum.gg

> Free World of Tanks stats for every player, clan and tank across EU, NA and Asia. WN8, WNX, winrate, tank progression, clan member rankings and history.

Stats are read from the official Wargaming API and snapshotted continuously,
so a profile carries its own history rather than a single point in time.
Nothing here needs an account, an API key or a paywall, and every page renders
server-side, so no JavaScript is required to read it.

## Read any page as Markdown

Every page has a Markdown twin. Append `.md` to its URL, or send
`Accept: text/markdown`. The response carries an `x-markdown-tokens` header,
so the cost of a page is known before its body is read. Each page also
declares its twin as `<link rel="alternate" type="text/markdown">`, and the
twin points back with a canonical `Link` header, so neither has to be guessed.

## Structured access

Prefer these over reading the pages. They answer the same questions with
typed payloads, and none of them need a key.

- [MCP server](https://unicum.gg/api/mcp): Streamable HTTP transport exposing 106 read-only tools, generated from the OpenAPI document below. Setup: https://unicum.gg/mcp.md
- [Agent Skill](https://unicum.gg/.well-known/agent-skills/wot-stats/SKILL.md): the whole API as a single skill file, listed in [the skills index](https://unicum.gg/.well-known/agent-skills/index.json).
- [OpenAPI document](https://unicum.gg/api/openapi.json): the public read API in full, unauthenticated.
- [API reference](https://unicum.gg/docs.md): the same document rendered per endpoint, one page each.
- [API catalog](https://unicum.gg/.well-known/api-catalog): RFC 9727 linkset pointing at the spec, the docs and the health endpoint.
- [MCP server card](https://unicum.gg/.well-known/mcp/server-card.json): the server's identity and remote transport.

## Regions

World of Tanks runs separate servers and an account exists on exactly one of
them. The region is the first path segment (`eu`, `na`, `asia`) and is required on
every entity: the same nickname on two servers is two different players.
Paths without a region are EU shortcuts.

## API reference

Base URL `https://unicum.gg/api`. Every endpoint is a GET returning JSON, apart from
the live channels, which stream Server-Sent Events.
